
此目录用于存放TabBar图标文件。

需要创建以下图标文件（建议尺寸 81x81 像素）：

- calendar.png (未选中状态)
- calendar-active.png (选中状态)
- booking.png (未选中状态)
- booking-active.png (选中状态)
- checkin.png (未选中状态)
- checkin-active.png (选中状态)
- private.png (未选中状态)
- private-active.png (选中状态)
- mine.png (未选中状态)
- mine-active.png (选中状态)

图标颜色建议：
- 未选中状态: #6b7280 (灰色)
- 选中状态: #2563eb (蓝色)

或者使用自定义图标颜色配置。
