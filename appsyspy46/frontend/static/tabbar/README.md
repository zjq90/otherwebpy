# TabBar 图标说明

本项目的 tabBar 需要以下图标文件（PNG 格式，建议尺寸 81x81 像素）：

## 所需图标

| 文件名 | 用途 | 状态 |
|--------|------|------|
| order.png | 订单图标（未选中） | 待添加 |
| order-active.png | 订单图标（选中） | 待添加 |
| route.png | 路线图标（未选中） | 待添加 |
| route-active.png | 路线图标（选中） | 待添加 |
| profile.png | 我的图标（未选中） | 待添加 |
| profile-active.png | 我的图标（选中） | 待添加 |

## 临时替代方案

在添加图标之前，tabBar 会显示文字而没有图标，功能不受影响。

## 图标设计建议

- 格式：PNG（支持透明背景）
- 尺寸：建议 81x81 像素（2倍图）
- 颜色：未选中图标使用灰色，选中图标使用主色调 (#2979ff)
